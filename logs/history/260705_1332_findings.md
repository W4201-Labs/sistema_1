# Technical Finding / Milestone

**Context**: M3 controls and audit cycles

## The Discovery

M3 can stay standard-agnostic by keeping control logic as data. The engine evaluates generic rule JSON with `all`, `any`, `eq`, `gte`, `lte`, `exists`, and `empty`; Convex only persists tenant-scoped rows and delegates decisions to the engine.

Cycle closure is guarded by control evaluation results, not by hard-coded requirement names or standard clauses. Closing a cycle freezes stored evaluations and writes a `cycle_close` snapshot.
