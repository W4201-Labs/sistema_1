# Problem Record (Troubleshooting)

**Severity**: Medium

## The Problem

Several environment/tooling issues appeared during M0 verification:

- `npx convex codegen` failed because no `CONVEX_DEPLOYMENT` is configured.
- Next production build failed without Clerk publishable key during prerender.
- Playwright initially failed because Chromium was not installed.
- `next lint` is deprecated and failed through the Next ESLint/Rushstack patch path.
- A concurrent `next build` and Playwright dev server run briefly collided on `.next` output.

## User-Requested Corrections

- User corrected scope: if the plan is phased, build only the first phase.
- User requested use of the `saver` skill to persist state.

## The Solution / Workaround

- Removed beyond-M0 domain modules and kept only foundation files.
- Added temporary local Convex `_generated` placeholders for typechecking until Convex is linked.
- Added Clerk env fallback in root/app/sign-in layouts and middleware.
- Installed Playwright Chromium with `npx playwright install chromium`.
- Replaced lint script with `eslint .` and simplified flat config; TypeScript correctness is covered by `tsc`.
- Reran production build alone after E2E to avoid `.next` collision.

## Learnings to Preserve

- Do not implement M1+ unless explicitly requested.
- Link Convex before relying on real generated Convex types.
- Keep Clerk fallbacks until real env vars are available.
- Avoid running `next build` concurrently with Playwright dev server in this workspace.
