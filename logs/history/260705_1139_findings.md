# Technical Finding / Milestone

**Context**: M2 Controlled documents implementation

## The Discovery

M2 fits the existing architecture without standard-specific branching by keeping document lifecycle rules in pure `engine/` code and leaving Convex responsible for auth, tenant scoping, persistence, and audit entries.

The lifecycle is data-independent and fixed for controlled documents: candidate versions move through review and approval, official files are required before effectivity, effective/approved official versions are immutable, and preparer self-approval is rejected.

Typed `documentRequirementLinks` allow a single document to support requirements from multiple standard packs while preserving generic link semantics such as `covers`, `supports`, `verifies`, and `justifies_na`.
