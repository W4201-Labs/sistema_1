# Technical Finding / Milestone

**Context**: M1 Tenancy & standards implementation

## The Discovery

M1 can be implemented on top of the M0 schema with a narrow schema extension for process hierarchy. The core agnostic behavior belongs in `engine/requirements`, while Convex modules stay thin: auth/scoping, persistence, generic import, and audit entries.

The standard-pack path is data-first:

- `seeds/standard-packs/*.json` stores only tenant-entered numbers, titles, and structure.
- `convex/import.ts` accepts `{ standard, requirements[] }` with stable keys and parent keys.
- `engine/requirements/tree.ts` renders nested trees and rollups without knowing any standard.
- `engine/requirements/applicability.ts` enforces governance fields for limited decisions and identifies coverage-relevant requirements.
