# Problem Record (Troubleshooting)

**Severity**: Medium

## The Problem

Verification initially failed when `npm run build` and `npm run e2e` ran in parallel. This reproduced the known `.next` collision from M0:

- `next build` failed collecting page data with missing page modules.
- Playwright reused a stale `next dev` process on port 3000.
- The stale server returned HTTP 500 with `Cannot find module './112.js'` from `.next/server/webpack-runtime.js`.

## User-Requested Corrections

- Implement M1 only.
- Use the `saver` skill only after finishing the implementation.

## The Solution / Workaround

- Re-ran `npm run build` alone; it passed.
- Checked port 3000 with `ss` and confirmed an old `next dev` / `next-server` process.
- Confirmed the stale server returned 500 with `curl`.
- Killed only the stale Next.js processes.
- Re-ran `npm run e2e`; both Playwright tests passed.

## Learnings to Preserve

- Never run `next build` concurrently with Playwright in this workspace.
- If Playwright reports missing UI text after a build collision, check whether port 3000 is serving stale `.next` artifacts.
- `reuseExistingServer: true` is not enough when the existing server responds with 500.
